# Focus Shield — Chrome Web Store Description (English)

Block distracting websites, create schedules and Focus Sessions, and keep your settings locally in Chrome.

Focus Shield helps you stay productive, focused, and free from online distractions. Designed with a clean, modern aesthetic, it provides powerful blocking features while respecting your privacy: 100% local, no account required, and zero telemetry.

### ✨ Key Features
- **Block Distracting Websites**: Block whole domains, specific URL paths (e.g. youtube.com/shorts), or keywords in URLs.
- **Exceptions (Allow List)**: Allow specific educational or work pages while blocking the rest of the site.
- **Focus Sessions (Pomodoro)**: Configurable work/break intervals (25m / 5m) with multi-cycle support and circular timer.
- **Strict Focus Mode**: Prevent impulse stops or list modifications during your focus sessions.
- **Schedules with Overnight Support**: Set automatic work-hours blocking (including schedules crossing midnight like 22:00–07:00).
- **Temporary Pause**: Pause blocking for 5m, 15m, 30m, 1h, or until manually resumed.
- **Master Password Protection**: Protect rules, schedules, and settings using Web Crypto PBKDF2 SHA-256 encryption.
- **Local Backup & Restore**: Export settings to JSON and restore via Merge or Replace modes.
- **Multilingual Support**: Switch seamlessly between English, Russian, and Ukrainian.

### 🔒 100% Private & Local
- No backend servers.
- No analytics or telemetry.
- No account registration.
- Browsing history is never recorded.
