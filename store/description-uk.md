# Focus Shield — Опис для Chrome Web Store (Українська)

Блокуйте сайти, що відволікають, створюйте розклади та фокус-сесії. Усі налаштування зберігаються локально.

Focus Shield допомагає зосередитися на роботі та навчанні, усуваючи цифровий шум. Розширення має стильний світлий дизайн, працює швидко та зберігає 100% конфіденційність: без акаунтів, без зовнішніх серверів та без збору даних.

### ✨ Ключові можливості
- **Блокування сайтів**: Блокування доменів, окремих шляхів URL (наприклад, youtube.com/shorts) та ключових слів в адресах.
- **Список винятків**: Дозвіл доступу до корисних сторінок заблокованих доменів.
- **Сесії фокусу (Pomodoro)**: Налаштування часу роботи й перерви (25 хв / 5 хв) з підтримкою циклів та круговим таймером.
- **Суворий режим (Strict Focus)**: Забороняє дострокове вимкнення фокусу або редагування списків.
- **Розклади з нічним режимом**: Автоматичне блокування за днями тижня та годинами (включно з нічними інтервалами 22:00–07:00).
- **Швидка пауза**: Призупинення блокування на 5, 15, 30, 60 хвилин або до ручного відновлення.
- **Захист паролем**: Захист видалення правил та налаштувань за допомогою PBKDF2 SHA-256 (Web Crypto).
- **Резервне копіювання**: Локальний експорт та імпорт налаштувань у форматі JSON (об'єднання або заміна).
- **Мови інтерфейсу**: Англійська, українська та російська мови з можливістю миттєвого перемикання.

### 🔒 Конфіденційність
- Усі дані зберігаються виключно на вашому комп'ютері.
- Жодних акаунтів, трекерів чи серверів.
